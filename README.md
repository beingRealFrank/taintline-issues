# Taintline

Free JetBrains IDE plugin for CodeQL queries. Works offline: no network calls, no data collection.

[![Downloads](https://img.shields.io/jetbrains/plugin/d/36120)](https://plugins.jetbrains.com/plugin/36120-taintline)

## Install

In your IDE: **Settings | Plugins | Marketplace**, search for **Taintline**, then **Install**. Or get it from [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/36120-taintline).

## Features

- Syntax highlighting for `.ql`, `.qll` and `.dbscheme` files
- Structure view of imports, modules, classes and predicates
- Commenting, brace matching and folding
- A run configuration for your local `codeql` CLI
